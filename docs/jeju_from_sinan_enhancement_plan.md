# 신안 답사지 요소를 활용한 제주 답사지 보완 계획

## 적용 원칙

- 신안 화면을 그대로 복제하지 않고 제주 현장에서 실제로 필요한 기능만 가져온다.
- 물때 배지는 조석이 접근 안전이나 관찰 결과에 영향을 주는 장소에만 표시한다.
- 교과 배지는 과목명만 붙이지 않고, `?` 도움말에서 무엇을 관찰하고 설명할지 제시한다.
- 한 장소의 교과 배지는 핵심 연계 2개를 기본으로 하고 특별한 경우에만 3개까지 허용한다.
- 제주에 이미 있는 학술 답사 설계, 신안 비교, 구조화 기록란과 겹치는 신안 요소는 추가하지 않는다.

## 신안에서 가져올 요소

1. `답사지 Ⅱ-1` 형식의 권역·장소 번호
2. 필수·권장·참고로 구분된 물때 배지와 국립해양조사원 연결
3. 교과명과 구체적인 현장 탐구 이유를 함께 보여 주는 도움말 배지
4. 지도, 네이버 지도, 물때 조회를 한곳에 모은 장소 도구 모음
5. 실제 현장 사진, 참고 사진, 개념 이미지를 구분하는 사진 상태 표시
6. 관찰 사실, 해석, 추가 질문을 구분하도록 돕는 짧은 기록 안내

## 제주에 가져오지 않을 요소

- 데이터 원문과 학생용 설명을 같은 화면에 반복해서 보여 주는 구성
- 모든 장소에 동일한 과목 배지를 일괄 부여하는 방식
- 조석과 관련 없는 실내·오름·시장 장소의 물때 배지
- 제주에 이미 있는 학술 답사 설계와 내용이 겹치는 원리 카드

## 물때 배지 1차 분류

| 수준 | 장소 | 표시 이유 |
|---|---|---|
| 필수 | 용머리해안 | 조석·파고·기상에 따라 출입 자체가 제한될 수 있음 |
| 권장 | 청굴물 | 조석 상태가 해안 용천수와 바닷물의 관계를 관찰하는 조건에 영향을 줌 |
| 권장 | 행원해변·코난해변 | 암반 노출 범위와 안전한 관찰 지점이 달라질 수 있음 |
| 권장 | 고망난돌 | 파랑과 젖은 암반 때문에 관찰 범위와 안전 판단이 필요함 |
| 권장 | 태웃개 | 암반 물웅덩이·해수 유입 상태와 파고를 함께 확인해야 함 |
| 권장 | 도구리알 | 해안 암반 노출과 파랑 접근 위험을 함께 판단해야 함 |
| 참고 | 이호테우해변·김녕해수욕장·함덕해수욕장 | 해변 폭과 물가 관찰 조건을 이해하는 참고 정보 |
| 보류 | 검은 모래 해변 현장 후보 | 정확한 장소와 접근 지점 확정 뒤 수준 결정 |

주상절리대·성산일출봉처럼 공식 탐방로나 전망대에서 관찰하는 장소는 바다와 가깝더라도 물때 배지를 기본 표시하지 않는다.

## 교과 연계 배지 설계

| 장소 유형 | 우선 교과 | 도움말에 제시할 탐구 내용 |
|---|---|---|
| 용천수·용암동굴·폭포 | 통합사회 1, 한국지리 탐구 | 화산 지질과 물의 이동이 생활·마을 입지에 미친 영향 |
| 응회구·화산 해안·주상절리·오름 | 통합사회 1, 한국지리 탐구 | 형성 작용, 기반 물질, 침식·풍화, 보전 필요성 |
| 해수욕장·해안 관광지 | 세계시민과 지리, 통합사회 1 | 자연 해안이 관광 공간으로 바뀌는 과정과 책임 있는 이용 |
| 항구·공항 | 통합사회 2, 한국지리 탐구 | 교통 결절점과 제주 생활권·관광 흐름의 변화 |
| 시장·관광 마을·농업 관광 | 통합사회 2, 세계시민과 지리 | 지역 경제, 장소 이미지, 주민 생활과 관광의 관계 |
| 미디어아트·야간 관광 | 세계시민과 지리, 통합사회 2 | 자연 이미지의 콘텐츠화와 관광 소비·지역 경관 변화 |

배지 도움말은 `이 장소는 통합사회 1과 연결됩니다` 같은 문장이 아니라 `용천수 위치와 마을 시설을 비교하여 자연환경이 생활에 준 영향을 확인합니다`처럼 학생 행동이 드러나는 문장으로 작성한다.

## 콘텐츠 보완 항목

### 1. 장소 상단 정보

- 영문 카테고리 대신 `핵심 용어` 3~4개를 표시한다.
- 확정·예비와 일정은 상태 정보로 유지하고, 교과·물때 배지와 시각적으로 구분한다.
- 해안 장소에만 물때 조회 버튼을 표시한다.

### 2. 권역별 역사·생활사

- 북서부: 항구·공항과 제주 도시권 성장
- 북동부: 용천수 중심 해안 마을과 생활용수 이용
- 동부: 성산의 어업·마을 경관과 세계유산 관광지화
- 서귀포: 폭포·시장·도심 관광이 결합된 지역 변화
- 남서부: 화산 해안의 보전, 관광 개발, 출입 통제
- 서부: 목축·차 재배·오름 경관이 관광 콘텐츠로 전환된 과정

각 권역에 접을 수 있는 `역사와 생활 경관` 읽을거리 2문단을 추가하되 장소별 기본·심화 해설과 반복하지 않는다.

### 3. 사진 신뢰도

- 실제 장소 사진은 `현장·장소 사진`으로 표시한다.
- 다른 제주 해안 사진을 대신 쓴 경우 `참고 사진·해당 장소 아님`을 사진 위에도 표시한다.
- 출처·저작자·라이선스는 현재처럼 유지한다.

### 4. 기록 활동

- 기존 제주 기록란 위에 `관찰 사실 → 해석 → 추가 질문` 안내를 한 줄로 추가한다.
- 교과 배지 도움말의 탐구 행동이 현장 미션 또는 기록란과 연결되는지 검토한다.

## 작업 순서

1. 장소 번호, 핵심 용어, 물때 분류 데이터 구조 추가
2. 장소 유형별 교과 연계 규칙 작성 후 26개 장소 개별 검토
3. 신안식 요소를 선별 적용한 제주 장소 상단 디자인 구현
4. 권역별 역사·생활사 읽을거리 추가
5. 참고 사진 상태 표시와 기록 안내 보완
6. 375px·768px·데스크톱 화면, 키보드 접근성, 인쇄 화면 검증

## 완료 기준

- 물때 배지가 없는 장소는 조석 확인이 실제로 불필요한 이유가 설명 가능해야 한다.
- 모든 교과 배지는 도움말에 구체적인 관찰 행동 또는 설명 과제를 포함해야 한다.
- 영문 카테고리가 학생 화면에 노출되지 않아야 한다.
- 장소 상단만 읽어도 위치 확인, 안전 확인, 핵심 탐구 방향을 파악할 수 있어야 한다.
- 모바일에서 배지와 도구가 본문을 밀어내거나 가로 넘침을 만들지 않아야 한다.
