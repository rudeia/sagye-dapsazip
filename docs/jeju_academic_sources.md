# 제주 답사지 학술 답사 출처와 기록 원칙

## 활용 원칙

- 현장 사진·관찰 기록은 **관찰 사실**이고, 형성 과정·원인에 대한 문장은 **해석**으로 분리한다.
- 예비 답사지의 좌표와 접근로는 수업 전 공공 지도·운영 공지·현장 사전답사로 다시 확인한다.
- 해안은 관찰 시각, 파고, 조석 상태를 함께 기록한다. 용천수·야생생물은 채취·접근·먹이 주기를 하지 않는다.
- 관광 안내 문구는 장소 운영자의 설명이므로, 지질·수문·생태의 일반 설명은 공공기관·국제기구 자료와 교차 확인한다.
- 카드의 **개념 출처**는 해석의 근거이며, **장소 확인** 링크는 운영 정보·위치·접근 조건을 사전에 확인하기 위한 자료다.

## 학생 기록 최소 단위

1. **위치**: 장소명, GPS, 관찰 시각, 날씨·조석 상태
2. **관찰 사실**: 사진·스케치로 확인한 구조·물질·시설·이용 행태
3. **해석 가설**: 관찰 사실을 바탕으로 한 형성 과정 또는 이용 방식의 설명
4. **반증 가능성**: 다른 시각·계절·지점에서 달라질 수 있는 요인
5. **비교**: 신안과 제주를 지질 기반, 물·퇴적 작용, 교통·관광 이용이라는 같은 기준으로 비교
