# 사계 답사집 학생 결과물 운영 계획

## 1. 운영 목적

사계 답사집은 답사지 자료와 학생 결과물을 함께 축적하는 디지털 답사 포트폴리오이다. 신안 섬 탐방기, 제주 답사기 등 지역별 답사지와 함께 학년도별 활동 책자, 사진 기록, 조별 보고서, 학생 제작 지도를 모아 다음 답사와 수업 자료로 재사용하는 것을 목표로 한다.

## 2. 대문 페이지 구성

대문 페이지는 다음 네 개의 탭으로 운영한다.

| 탭 | 역할 |
|---|---|
| 답사지 둘러보기 | 신안, 제주 등 지역별 답사지로 이동 |
| 학생 결과물 | 2024학년도, 2025학년도 결과물 페이지로 이동 |
| 활동 안내 | 사진 기록, 위치 기록, 보고서 작성 기준 안내 |
| 사계 동아리 소개 | 동아리의 목적과 프로젝트 방향 소개 |

## 3. 학생 결과물 탭 구성

학생 결과물 탭에는 학년도별 카드를 배치한다.

```text
학생 결과물
├─ 2024학년도 결과물
│  ├─ 활동 책자 PDF
│  ├─ 사진 갤러리
│  └─ 조별 보고서
└─ 2025학년도 결과물
   ├─ 활동 책자 PDF
   ├─ 사진 갤러리
   └─ 조별 보고서
```

## 5. 자료 유형별 운영 방식

### 5.1 활동 책자 PDF

- 파일명은 `booklet.pdf`로 두면 연도별 결과물 페이지에서 바로 연결된다.
- 예: `results/2024/booklet.pdf`, `results/2025/booklet.pdf`
- 책자 안에 학생 이름, 얼굴, 학번, 연락처가 있으면 외부 공개 전 삭제하거나 가린다.

### 5.2 사진 갤러리

사진은 연도별 `images` 폴더에 넣는다.

```text
results/2024/images/2024_sinan_01.jpg
results/2024/images/2024_sinan_02.jpg
results/2025/images/2025_jeju_01.jpg
```

사진 카드에는 다음 정보를 넣는다.

| 항목 | 예시 |
|---|---|
| 사진 제목 | 대광해수욕장 방풍림 |
| 장소명 | 신안군 임자도 대광해수욕장 |
| 촬영 주체 | 1조 또는 A팀 |
| 설명 | 해송 숲 안팎의 바람 차이를 관찰함 |
| 키워드 | 해안 사구, 방풍림, 미기후 |

### 5.3 조별 보고서

- 학생 이름 대신 `1조`, `2조`, `A팀`처럼 표시한다.
- 원문 전체 공개가 부담되면 대표 문장과 PDF 다운로드 링크만 제공한다.
- 보고서에는 관찰 사실, 지리적 해석, 추가 질문이 드러나도록 정리한다.

## 6. 개인정보 및 저작권 점검

공개 전 반드시 확인할 내용은 다음과 같다.

- 학생 얼굴이 선명하게 보이는 사진은 모자이크하거나 비공개 처리한다.
- 이름, 학번, 연락처, 주소 등 개인정보는 삭제한다.
- 외부 이미지나 지도 캡처는 사용 조건을 확인한다.
- 학생 촬영 사진을 우선 사용한다.
- 외부 공개가 어려운 자료는 학교 내부 공유용으로만 운영한다.

## 7. 사진 용량 기준

- 긴 변 기준 1600px 이하 권장
- 사진 1장당 300KB~800KB 권장
- 원본 사진을 그대로 올리면 GitHub Pages 로딩이 느려질 수 있다.

## 8. Codex와 연동해 수정할 때 요청 예시

```text
이 프로젝트에서 2024학년도 결과물 페이지에 활동 책자 PDF 링크와 대표 사진 6장을 추가해줘.
사진은 results/2024/images 폴더의 파일을 사용하고, 각 사진 카드에는 장소명과 설명을 넣어줘.
```

```text
results/2025/gallery.html의 사진 카드 개수를 12개로 늘리고, 모바일에서 한 줄에 한 장씩 보이도록 조정해줘.
```

```text
대문 페이지의 학생 결과물 탭에 2026학년도 카드를 추가하고, results/2026 폴더 구조도 만들어줘.
```

## 9. 향후 확장 방향

1. 제주 답사기 추가
2. 연도별 결과물 누적
3. 조별 보고서 PDF 연결
4. 학생 제작 지도 또는 StoryMap 연결
5. 활동 평가 루브릭 페이지 추가
