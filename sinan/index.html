18개 답사지 위치 확인

여섯 섬의 대표색을 함께 사용한 전체 답사지 지도입니다. 마커 색으로 섬을 구분해 보세요.

지도가 좁게 보이면 아래의 ‘지도 다시 불러오기’를 누르거나 화면을 한 번 회전해 보세요.
국립해양조사원 물때 조회 OpenStreetMap에서 보기 신안군 네이버 지도
지도가 보이지 않으면 인터넷 연결, 학교망의 외부 지도 차단, 또는 Leaflet CDN 로딩 제한 때문일 수 있습니다. 이 경우 각 답사지 카드의 지도에서 보기 또는 입력 좌표 지도 표시 버튼을 사용해 새 창 지도로 확인하세요.

※ 지도 마커는 공식 주소와 공개 지도 좌표를 바탕으로 보정했습니다. 다만 자연 지형 또는 접근 지점이 여러 개인 장소는 수업용 개략 위치이므로, 실제 이동 전에는 교사의 안내와 공식 지도, 현장 안전 정보를 함께 확인하세요.
○ 흰색 테두리 마커는 기본 위치, 검은색 테두리 마커는 학생이 입력한 좌표입니다. 학생 좌표를 입력하면 해당 답사지의 기본 마커는 숨겨지고, 입력값을 지우면 기본 마커가 다시 나타납니다.
